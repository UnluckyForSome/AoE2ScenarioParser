# AoE2ScenarioParser (archived)

**This Python fork has been superseded by [aoe2-mcscenarioparser](https://github.com/UnluckyForSome/aoe2-mcscenarioparser).**

The JavaScript module is used by [Pages-AOE2Museum](https://github.com/UnluckyForSome/Pages-AOE2Museum) for in-browser scenario parsing, analysis, and DE conversion.

This fork provided Definitive Edition scenario parsing for the museum. That surface is now part of the unified `aoe2-mcscenarioparser` module.

Pinned copies remain in `sourcemodules/` via `fetch-pylibs` for parity harnesses until `build/parity/oracle-scenario.py` is retired.
